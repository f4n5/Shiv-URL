How this works · supported · Spotify note
  • This page talks to a Cobalt API instance (open-source media downloader). No accounts, no tracking on this page.
  • YouTube, Shorts, Music · TikTok · Instagram · X/Twitter · Reddit · SoundCloud · Vimeo · Twitch clips · and more depending on the instance.
  • Spotify: Cobalt does not pull Spotify streams directly (DRM). Use a track share link if the instance maps it, or paste the matching YouTube / SoundCloud link instead. For bulk Spotify → files, use desktop tools like spotDL (YouTube matching) on your machine.
  • Official api.cobalt.tools often has Turnstile / rate limits and may disable YouTube. Prefer a community instance from the dropdown, or run your own (Docker, see cobalt GitHub).
  • Response is a short-lived tunnel URL — click Download quickly. Nothing is stored on this page except recent URLs in localStorage.
  • Pure frontend. Open the HTML file locally or host it anywhere. Change instance anytime.
